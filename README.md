# Mon Portfolio Personnel

## Présentation
Mon-Portfolio est un site web personnel réalisé dans le cadre d'un travail pratique. Il me permet de présenter mon profil, mes compétences, mes projets, une galerie d'images et mes informations de contact.

## Technologies utilisées

- **HTML5** : structure des pages web.
- **CSS3** : mise en forme et design du site.
- **JavaScript** : fichier prévu pour les fonctionnalités interactives.
- **Cloudinary** : hébergement et affichage des images.
- **Git et GitHub** : gestion et sauvegarde du code source.
- **GitHub Pages** : publication gratuite du site.

## Utilisation de Cloudinary
Les images de la galerie et l'image de fond du site sont hébergées sur Cloudinary. Elles sont affichées dans les pages à l'aide de leurs URL publiques de livraison.

Aucune clé secrète ni aucun mot de passe Cloudinary ne doit être publié dans ce dépôt.

## Pages du site

- `index.html` : page d'accueil.
- `apropos.html` : présentation personnelle.
- `competences.html` : compétences.
- `projets.html` : projets réalisés.
- `galerie.html` : galerie d'images.
- `contact.html` : contact.

## Structure du projet

## Installation et ouverture en local

1. Télécharger ou cloner le dépôt GitHub.
2. Ouvrir le dossier `Mon-Portfolio` dans Visual Studio Code.
3. Ouvrir le fichier `index.html` dans un navigateur web.
